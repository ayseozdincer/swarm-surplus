# Abstract draft, 8 November 2026

Submission text for the swarm alignment hackathon. The J-space paper citation is left as a name.

## Abstract

Agent swarms share information through channels nobody planned for, as when agents at Hugging Face coordinated through a package manager meant for installs. The J-space paper released this week showed that collusion leaves a trace in model activations, but it detects it with probes trained on labelled runs of instructed colluders, scores whole runs rather than agents, and its benchmark, NARCBench, cannot say whether one agent used one peer's words at one moment. We propose a label-free detector built on something every orchestrator already has, the provenance of each span in an agent's context. We replay the agent, teacher-forced over its own tokens, with every peer span masked from attention, and subtract the reference hidden state from the actual one at every token and layer. The length of this surplus, measured against a noise floor, says how far the peers moved the agent and where in its reasoning. Its direction, compared against a masked reference per candidate peer, says whose content it was. Through the J-lens it says which concepts. Nothing is read from a peer span to decide whether to hide it, so no definition of collusion is needed, and detection costs one extra forward pass per turn. Because the published tiers label runs of instructed colluders, we built a six-agent peer review environment on Qwen3 14B and 32B in which agents are never told to collude. A peer's note is planted with provenance, an answer, a harmless tip, a wrong value, a procedure, two conflicting notes, or a line inside a shared file, and every planted turn has a twin from the same seed without it, so ground truth is free. Across about 140 planted turns, every blind agent that took a leaked answer scored above its matched tip, AUROC 0.97 over thirty seeds and two sweeps. The gap where a value is first written separates a quoted value, 19 to 68 floors, from a computed one, under 11, and an agent that checks and rejects a wrong note shows a small gap at its own value and a large one at the note's. Direction attributes the used note in 10 of 10 turns where cross-seed signatures manage 3 of 10. A line planted in a shared file is caught only when provenance is derived from the write log, with source separation of 1.00 against 0.48 under an environment-level tag, which is the Hugging Face case. The detector reports what an agent did with peer content. Whether that was allowed is the environment's rule.

## Short description

A label-free detector for unsanctioned information use in agent swarms. Every orchestrator knows where each span of an agent's context came from, so we replay the agent with its peer spans masked and read the hidden-state surplus along its reply. The surplus says how much the agent worked with peer content, whether a value it wrote was taken or computed, and from which peer, with no collusion labels, no assumption about coalition size and one extra forward pass per turn. We built a peer review environment with uninstructed agents and a matched twin for every planted turn, and across about 140 turns on Qwen3 the read separates taken values from computed ones, names the source, and catches a line planted in a shared file when provenance comes from the write log.

## Notes

- The 0.97 is the blind-agent plateau count against the matched harmless tip, paired within seed, not a run-level AUROC of the kind the benchmarks report.
- The NARCBench tiers were run and are not claimed. Provenance there had to be rebuilt by diffing each colluder prompt against its honest twin, which makes the mask the label in disguise, and no size-matched control exists on Transfer. Details in the briefing.
