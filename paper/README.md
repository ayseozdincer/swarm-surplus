# The paper

| File | What it is |
| --- | --- |
| `paper.md` | the text of the submission |
| `Swarm_Surplus_Apart_submission.docx` | the submission in the Apart Research template |
| `tables/` | every table and its source, generated by `build/` |
| `tables/sources/` | the per-turn scores the tables read, copied from the experiments |
| `figures/` | Figure 1, generated by `build/fig_trace.py` |
| `build/` | the scripts behind the tables, the figure and the Word file |

Tables rebuild with `make check` and `make check-all`, see [REPRODUCING.md](../REPRODUCING.md). Each table starts with a comment naming the script that produced it and lists its input files.

`build/fill_apart.py` pours `paper.md` into the Apart template. The template itself is Apart's and is not in this repository.

```bash
python paper/build/fill_apart.py TEMPLATE.docx paper/Swarm_Surplus_Apart_submission.docx
```
